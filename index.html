    Method and honest limits

    Intended learner
    A student using a screen reader or keyboard-only navigation in a course page.
    Task
    Find the week's reading and submit an assignment without needing a pointer or visual-only cues.
    Barrier removed
    The teacher usually never learns that the page is unusable until a student gives up. The audit makes concrete barriers visible before publication.

    What the score means

    Coverage is counted as passed checks plus half credit for borderline checks, divided by the eight checks in this prototype. It is a triage number, never WCAG certification.

    Static-audit limits

    • No JavaScript execution, external CSS loading, rendering measurement or network fetch.
    • Contrast uses inline styles and unprefixed Tailwind-ish color hints. Unknown declarations fall back to black text on white.
    • Accessible names, table structure and custom keyboard behavior are approximations that need real browser and assistive-technology testing.

    A11yClass runs entirely in the browser. Synthetic examples only. No student records, grades, accounts or network calls.
